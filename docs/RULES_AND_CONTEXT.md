# 规则 数值与上下文怎样理解

更新于2026年10月31日。当前主入口是一整局训练，最多60回合，支持四个固定场景和两档对手。旧版单回合练习另有页面，不是主流程。

## 哪些是预先设定的

宠物、等级、招式和初始配置固定，规则来自Showdown 0.11.11，伤害区间来自Smogon calc 0.12.0。模型不编造面板、扣血或命中结果。

训练局使用自定义短局次数，双方一致；标准对手随机选合法行动，进阶对手按公开直接伤害和命中评分。具体次数见[资源规则](SHORT_MATCH_RESOURCES.md)，进阶策略见[Agent说明](AGENT_EXECUTION_DESIGN.md)。这些都不代表真实洛克王国机制。

## 技能和防御到底在说什么

- **属性**决定克制、抵抗或免疫，例如某招打某属性更有效。
- **物理或特殊**决定比较哪组数值：物理看攻击对防御，特殊看特攻对特防。防御和特防不能混用。
- **威力**只是招式参数，不等于扣血。等级、攻防、属性、本系等都会影响伤害，计算器已经把相关因素算进区间，不能再重复乘一次属性倍率。
- **命中**和**出手顺序**是两回事。标称命中是基础参数；出手顺序还涉及优先度和速度等，实际由引擎结算。

例如固定电系场景中，十万伏特是特殊招式，要看对手特防；电光一闪是物理招式，要看防御。初始配置下，前者命中时的计算区间为86～104，对手生命119，所以不能解释为满血必定一击击败。这只是该配置的例子，不是所有局面的固定伤害。

## 哪些信息什么时候给教练

局中给公开状态和观察方向，让玩家自己选；不开放逐招伤害排名或替代行动试算。赛后才能查看整局、具体回合和计算，比较另一招的一回合结果。不能把赛后知道的信息说成玩家出招时已经看到。

进阶评分“直接伤害区间均值×标称命中率”只是一条简化策略，不是胜率，也没完整考虑控制、资源和先手价值。

## 上下文不是一种东西

| 信息 | 用来做什么 | 当前做法 |
| --- | --- | --- |
| 当前局面 | 知道游戏发生到哪一步 | 引擎事实，按局中或赛后限制可见范围 |
| 近期对话 | 理解“这个”“再来一次”等指代 | 普通回应取六轮，语义规划五轮，工具Agent窗口更短 |
| 明确偏好与学习摘要 | 延续讲解方式和最近练习重点 | 本地保存偏好，学习摘要取最近五条 |
| 本次工具结果 | 支持当前回答 | 只能引用实际读过的证据，受调用预算限制 |
| RAG资料 | 查通用规则 | 26条公开资料，不是玩家个人记忆 |

完整对局记录保存在SQLite，刷新可恢复；模型每次只拿必要部分，不会把所有历史都放进提示。界面显示多少条消息，也不等于模型读了多少轮。

失败草稿可回看，但不作为正常事实进入后续对话。没有全历史语义检索、自动长期人格提炼或经过验证的掌握度模型。

## 记录和验证给谁看

玩家看记录，是为了回顾发生过什么；开发者看工具记录，是为了查回答用了哪些资料、操作是否执行、哪里失败。记录不是玩家能力认证，也不是模型隐藏思考。

哈希相同可以帮助确认记录没变，引用有效可以确认资料确实读过；二者都不能单独证明模型解释正确。实际成绩和边界统一见[验证说明](VALIDATION.md)。
