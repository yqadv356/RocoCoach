# 交付工程记录

2026年10月30日。这里只保留适合公开的工程决策与验证范围；本机完整开发日志、私人对局和旧截图不进入公开交付包。

## 从单回合到整局

早期只做一次行动与小测，无法展现连续陪练。主流程改为整局账本，每次行动保留出招前后快照、玩家理由和真实结果；老师复盘引用整局及具体回合。主动引导只看到公开状态，排名和反事实赛后开放。保留旧练习页面，但提交稿不把它说成当前自动课程。

## 规则与体验

没有游戏接口时复用固定版本Showdown和Smogon，避免模型自编伤害。长局次数对短局几乎没有约束，新增双方一致、版本化的短局额度；引擎实际扣减、耗尽禁用、全耗尽挣扎。旧局按原规则重放，不回写历史。进阶对手真实改变选招策略，但只是公开直接伤害/命中启发式，不是最优战术或平衡结论。

## 模型与证据

实际接入千问，工具Agent受阶段、参数、预算和证据引用约束。RAG由4条原则扩至26条固定来源，记录查询、候选分数、版本与哈希。首次留出失败保留，修正后的同题成绩仅称回归；没有向量数据库或RL训练。

## 流式消失与终局等待

连续反馈暴露多个不同根因：展示层英文过滤、完成片段的整页交接、末尾校验失败清空草稿。早期测试只覆盖成功，甚至错误要求失败正文消失。调整为请求ID绑定消息生命周期、可见草稿检查点、原位完成/失败和刷新恢复；失败草稿不进入事实上下文。自动复盘冻结快照、宿主预读必要证据、后台总结，减少串行模型往返。不是生产队列，未承诺无延迟。

## 从口头答应到实际操作

助手曾反复询问是否开局，却不能承接确认。先增加结构化待办与幂等事务，之后将在线短语路由改成完整上下文语义计划；有限规则单独留离线演示。真正创建新局并核验后才报告成功。模型探索两轮均13/14，保留含糊重试误判；对替换未结束整局增加语义副作用核对，仍不能保证所有语言理解。
